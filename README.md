# Anti Addiction Timer

An Android app for limiting app usage and reducing short-video addiction.

## Features

- Timer for app usage
- Warning after time limit
- App blacklist (planned)
- Background monitoring (planned)
- Custom limit settings (planned)

## Tech

- Kotlin
- Android Studio
- Jetpack Compose
- Git
- GitHub

## Version

v0.1 - timer base  
v0.2 - show installed apps  
v0.3 - filter user apps  
v0.4 - add package query permission  
v0.5 - detect current foreground app using UsageStatsManager
